# 已废弃：LLM-B 的 Dify 工作流

**LLM-B 于 2026-08-27 由走 Dify 改为直连模型 API**（设计方案 §13.2.0）。

`dish_tag.workflow.yml.deprecated` 是当时按 Dify 1.6.0 DSL 结构写的设计稿，
**从未做过导入→导出→往返验证，不是可用的交付物**。保留它只为记录当时的编排形态，
将来若要回到编排平台可以少推一遍。

改直连的理由不是数据敏感度——LLM-B 的请求里只有菜名、食材名、重量与枚举展示名，
一条健康数据都没有。理由是原方案的 D1 已经决定提示词正文放在 Java 侧，
于是工作流退化成「输入 → LLM → 输出」三个节点的纯转发，**收益归零而成本仍在**：
一份会漂移的 schema 副本、一处 `modelVersion` 双真源、两条只为锁 DSL 而存在的契约测试。

当前接入契约见设计方案 §13.2，实现见 `infra/OpenAiCompatibleDishTagClient.java`。
